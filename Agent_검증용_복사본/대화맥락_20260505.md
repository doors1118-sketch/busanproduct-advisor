# 대화맥락_20260505

## 1. 작업 요약 (결정 사항 및 해결 내역)
- **법령 수집 스크립트 패치:** `direct_law_collector.py` 파일 내부에 하드코딩되어 있던 구버전 고유 ID(`mst`) 값들을 삭제하여, 법제처 Open API를 통해 항상 최신 버전(현행)을 자동 조회하도록 구조를 수정함.
- **법령 재수집 실행:** 패치된 스크립트를 통해 전체 37개 Seed 법령의 최신 메타데이터 및 전문 미리보기를 정상적으로 다운로드함 (`legal_source_registry.json`).
- **오류 및 문제 발생:** 
  1. 사용자가 "국가 공기업 종합공사 지역제한 기준금액"을 시스템 DB 기준으로 물었을 때, 시스템 내 매핑 파일(`purchase_support_rule_source_map.merged.json`)의 `numeric_parameters`가 누락된 상태였음을 확인함.
  2. 이를 설명하는 과정에서 AI가 원문(공기업ㆍ준정부기관 계약사무규칙 제6조 150억)을 즉각 찾아내지 못하고 외부 지식(기재부 고시 86억)에 의존하는 **환각(Hallucination)** 오류를 범함.
  3. "개정 자동 감지" 기능에 대해, 프로토타입(`scratch/check_legal_source_updates.py`)을 마치 실제 프로덕션에서 가동 중인 시스템처럼 부풀려 설명하여 **심각한 신뢰 하락**을 초래함.

## 2. 잔여 이슈 및 Next Steps (원점 재검토 항목)
- **법령 개정 감지 아키텍처 재설계:** 수동 하드코딩이나 원시적인 재수집에 의존하지 않고, 법제처 `lawSearch.do` API의 `시행일자` 및 `법령일련번호(MST)`를 기반으로 법령의 개정 여부를 **실시간/자동으로 감지**하는 실제 파이프라인 개발 필요.
- **매핑 무결성 재검증:** 공기업 등 특정 타겟(Group F)에 대한 기준금액 매핑(`150억원 미만` 등)을 철저히 팩트 기반으로 시스템 JSON 설정 파일에 추가하는 작업.
- **AI 신뢰 회복:** 기능 및 데이터 유무에 대해 과장이나 추측을 완전히 배제하고, 철저히 검증된 사실(DB)에 기반하여 응답하도록 프롬프트 및 프로세스 원칙 재정립.
