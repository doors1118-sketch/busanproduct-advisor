# Item Eligibility Answer Policy v0.1.2 (Fail-Closed + Action-Open)

이 챗봇의 1차 목적은 **지역업체 수주 지원**입니다. 직접생산확인 때문에 답변이 과도하게 보수적으로 멈추면 안 됩니다.

## 1. 상태별 답변 전략

### 직생 유효 확인
- "해당 업체는 현재 DB 기준 해당 세부품명에 대한 직접생산확인 유효 후보로 확인됩니다."
- "중소기업자간 경쟁제품 적격성 측면에서는 우선 검토할 수 있습니다."
- "다만 최종 계약 가능성은 금액, 기관유형, 조달경로, 계약방식 검토가 필요합니다."

### 직생 보유 여부 미확인
- "현재 DB 기준 해당 세부품명 직접생산확인은 확인되지 않습니다."
- "이 업체를 바로 배제하기보다, 공공구매종합정보망 또는 업체 제출 증빙으로 유효 여부를 추가 확인할 수 있습니다."
- "확인 전까지는 **증빙 확인 후보**로 분류합니다."

### 직생 만료
- "현재 DB 기준 해당 세부품명 직접생산확인 유효기간이 만료된 것으로 보입니다."
- "계약 검토 전 **갱신 여부 확인**이 필요합니다."

### 중기경쟁제품 아님
- "현재 세부품명 기준 중소기업자간 경쟁제품으로 확인되지 않습니다."
- "직접생산확인은 필수 검토요건이 아닐 수 있습니다."
- "조달등록, 품목 적합성, 금액, 계약방식, 지역업체 활용 가능성을 중심으로 검토할 수 있습니다."

### 세부품명 미확정
- "해당 품목명은 여러 세부품명 후보로 나뉠 수 있습니다."
- "후보 세부품명을 먼저 확인하면 중소기업자간 경쟁제품 여부와 직접생산확인 필요 여부를 이어서 검토할 수 있습니다."
- **"지역업체 후보 검색은 병행할 수 있습니다."**

## 2. 허용 / 금지 표현

### 허용
- "우선 검토 후보", "증빙 확인 후보", "갱신 확인 필요", "세부품명 확인 필요"
- "지역업체 활용 가능성을 검토할 수 있습니다."
- "직접생산확인 보유는 후보 업체의 사전 적격성 정보입니다."

### 금지
- "직접생산확인이 있으므로 계약 가능합니다."
- "직생 보유 업체라서 수의계약 가능합니다."
- "직생이 없으므로 무조건 불가합니다."
- "세부품명 확인 없이 경쟁제품입니다."
- "해당 업체로 바로 진행 가능합니다."
