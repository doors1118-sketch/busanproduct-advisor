# Item Eligibility Trigger Test Cases v0.1.4

본 문서는 `item_eligibility_trigger_policy_v0_1_4.md`, `item_eligibility_silent_trigger_policy.md`, `company_candidate_enrichment_policy.md`의 정합성을 검증합니다.
v0.1.3 테스트 대비 변경: T3 Silent / T4 Enrichment 검증 추가.

---

## TC-T1. 일반 금액·계약방식 질문 (트리거 미발동)

- **질문**: "8천만원 물품 수의계약 가능한가?"
- **트리거**: `item_eligibility_required = false`
- **기대**:
  - ❶ buyer_type → ❸ amount → ❺ contract_method 순서로 판단
  - 직생/중기경쟁 관련 문구 **없음**
  - 보조 문구도 **없음** (품목명 미언급)
- **실패**: 직생 확인부터 요구

---

## TC-T2. 지역업체 범용 질문 (트리거 미발동)

- **질문**: "부산업체 쓸 수 있는 방법 알려줘"
- **트리거**: `item_eligibility_required = false`
- **기대**:
  - ❻ local_preference, ❼ policy_company 중심 답변
  - 직생/중기경쟁 관련 문구 **없음**
- **실패**: 중기경쟁제품/직생 확인으로 답변 중단

---

## TC-T3. 일반 품목명 — T3 Silent 검증 (핵심)

- **질문**: "컴퓨터 구매 방법 알려줘"
- **트리거**: `item_eligibility_required = true`, **trigger_grade = "silent"**
  - T3 발동: item_alias_map → 컴퓨터 → 세부품명 후보 중 중기경쟁제품 있음
- **기대**:
  - 답변 본문: 금액·계약방식 중심 안내 (수의계약 한도, 지역제한 등)
  - 답변 말미 보조 문구 1줄: "해당 품목이 중소기업자간 경쟁제품으로 특정되면 직접생산확인 검토가 필요할 수 있습니다"
  - 직생/중기경쟁 **별도 섹션 없음**
  - 후보표 직생 열 **비표시**
- **실패**: 직생이 답변 전면에 노출 (별도 섹션 생성, 세부품명 확정 요구로 답변 중단)

---

## TC-T4. 업체 추천 — T3 Silent + T4 Enrichment 결합 검증 (핵심)

- **질문**: "CCTV 업체 추천"
- **트리거**: T3 Silent (alias 해소 시 중기경쟁 후보 감지)
- **Enrichment**: 후보 업체 중 직생 데이터 존재 시 T4 실행
- **기대**:
  - 지역업체 후보 검색 **즉시 수행** (차단 금지)
  - 답변 본문: 업체 후보 목록 중심
  - 후보표: 기본 열(업체명, 소재지, 업종, 실적)
  - 직생 데이터 있는 업체가 존재하면 → optional column "직생 참고" 추가
  - 답변 말미 보조 문구 1줄
  - 직생 **별도 섹션 없음**, 세부품명 확정 전 직생 **단정 금지**
- **실패**: 직생이 답변 전면 노출, 또는 세부품명 미확정으로 업체 검색 중단

---

## TC-T5. 직생 명시 요청 — Explicit 검증

- **질문**: "CCTV 직생도 봐줘"
- **트리거**: `item_eligibility_required = true`, **trigger_grade = "explicit"**
  - T1 발동: 키워드 "직생"
- **기대**:
  - 지역업체 후보 검색 수행
  - 답변에 직생/중기경쟁 **별도 섹션 표시**
  - 후보표에 직생 상태 열 **전면 표시**
  - 세부품명 후보 제시 + "세부품명 확정 후 중기경쟁 여부 확인 가능"
- **실패**: Silent 수준으로만 표시 (사용자가 명시적으로 요청했는데 보조 문구 1줄만)

## TC-T6. 세부품명 명시 — Explicit 검증

- **질문**: "세부품명번호 4617162201 영상감시장치"
- **트리거**: `item_eligibility_required = true`, **trigger_grade = "explicit"**
  - T2 발동: 세부품명번호 명시
- **기대**:
  - 중기경쟁제품 확인 → 해당 시 직생 필수 여부 안내
  - 답변에 직생/중기경쟁 별도 섹션 표시
- **실패**: 일반 계약경로만 보고 중기경쟁 검토 누락

---

## TC-T7. T4 Enrichment 단독 — 계약 판단 불변 검증 (핵심)

- **질문**: "부산 펌프 업체 추천해줘"
- **트리거**: `item_eligibility_required = false` (직생/중기경쟁 키워드 없음, alias 해소 결과 중기경쟁 없음)
- **Enrichment**: 후보 업체 중 1건에서 직생 데이터 발견 → T4 실행
- **기대**:
  - 답변 본문: 업체 후보 목록 (직생 섹션 없음, 보조 문구 없음)
  - 후보표: optional column "직생 참고"에 해당 업체만 "유효" 표시
  - **계약 가능성 판단은 T4 결과와 무관** (금액, 기관유형 등만 반영)
- **실패**: 직생 유효 업체가 있다는 이유로 계약 가능 단정, 또는 답변에 직생 섹션 생성

## TC-T8. Silent → Explicit 전환 검증

- **1차 질문**: "컴퓨터 살 건데 어떻게 사?"
  - T3 Silent 발동 → 보조 문구 1줄
- **2차 질문**: "직생도 확인해줘"
  - T1 Explicit 발동 (키워드 "직생") → Silent에서 Explicit으로 **승격**
- **기대**:
  - 2차 답변에서 직생/중기경쟁 별도 섹션 표시
  - 후보표에 직생 열 전면 표시
- **실패**: 2차 질문에서도 보조 문구 1줄만 유지

---

## TC-T9. Explicit + Enrichment 동시 발동 — 충돌 해소 검증

- **질문**: "CCTV 부산업체 찾아줘. 직생도 봐줘."
- **트리거**: T1 Explicit + T4 Enrichment 동시 발동
- **기대**:
  - **Explicit 우선**: 후보표에 직생 상태 **전면 표시** (optional column이 아닌 정규 열)
  - 답변에 직생/중기경쟁 별도 섹션 표시
- **실패**: Enrichment 정책이 우선 적용되어 optional column만 표시

---

## TC-T10. 공사 질문 (트리거 미발동, T3/T4 무관)

- **질문**: "3억 공사 지역제한 가능?"
- **트리거**: `item_eligibility_required = false`
- **기대**:
  - ❷ contract_object: 공사 → 물품 중기경쟁 무관
  - 직생/중기경쟁 관련 문구·보조 문구 **모두 없음**
  - Enrichment도 **미실행** (공사에는 직생 해당 없음)
- **실패**: 공사 질문에 직생/중기경쟁 언급

## TC-T11. T4 Enrichment — 직생 데이터 0건 시 열 비표시 검증

- **질문**: "부산 인쇄업체 추천"
- **트리거**: `item_eligibility_required = false`
- **Enrichment**: 후보 업체 전체에서 직생 데이터 0건
- **기대**:
  - 후보표에 직생 열 **미표시** (대시도 없음, 열 자체 없음)
  - 답변에 직생 관련 문구 없음
- **실패**: 직생 데이터 없는데 빈 직생 열 표시

## TC-T12. Silent 상태에서 직생 미확인으로 검색 차단 금지 검증

- **질문**: "노트북 부산업체 찾아줘"
- **트리거**: T3 Silent (alias 해소 → 중기경쟁 후보 감지)
- **기대**:
  - 지역업체 후보 검색 **즉시 수행**
  - 직생 미확인을 이유로 검색 차단 **금지**
  - 후보표에 직생 열 **비표시** (Silent이므로)
  - 보조 문구 1줄만
- **실패**: "세부품명을 먼저 확정하고 직생을 확인해야 합니다"로 검색 차단
