# Item Eligibility 후보표 정책

## 후보표 열 구성
지역업체 후보표에는 기존 열에 더해 다음 열을 추가합니다.

| 열 | 설명 |
|---|---|
| 세부품명 매칭 | detail_item_code 확정 여부 |
| 중기경쟁제품 여부 | is_sme_competition_product |
| 직접생산확인 필요 여부 | direct_production_required |
| 업체 직생 상태 | cert_status (valid/expired/unknown) |
| 검토 상태 | eligibility_status |
| 다음 조치 | candidate_action |

## 후보 상태 표현
- **우선 검토 후보**: 직생 유효, 중기경쟁 확인, 세부품명 확정
- **증빙 확인 후보**: 직생 미확인이나 업체 자체는 지역업체 해당
- **갱신 확인 필요**: 직생 만료, 갱신 증빙 확인 필요
- **세부품명 확인 필요**: 일반 품목명만 확인, 세부품명 미확정
- **지역업체 활용 가능성 검토**: 중기경쟁제품 아닌 경우 별도 경로 검토

## 정렬 우선순위
1. 우선 검토 후보 (직생 유효)
2. 증빙 확인 후보 (직생 미확인)
3. 갱신 확인 필요 (직생 만료)
4. 세부품명 확인 필요
