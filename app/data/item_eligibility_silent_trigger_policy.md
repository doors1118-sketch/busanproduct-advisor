# Item Eligibility Silent Trigger Policy

본 문서는 T3 트리거(item_alias_map이 중기경쟁제품 후보를 감지한 경우)가 **Silent** 등급으로 동작하는 규칙을 정의합니다.

## 1. 문제 정의

T3는 사용자가 "컴퓨터 구매", "CCTV 업체 추천" 등 일반 품목명을 언급했을 때, item_alias_map 조회 결과 중기경쟁제품 후보가 포함되면 Item Eligibility를 호출합니다.
이 트리거가 Explicit으로 동작하면 **직생/중기경쟁이 답변 전면에 노출되어 과도하게 보수적인 답변**을 생성합니다.

**예시 — T3가 Explicit일 때 (문제):**
```
Q: "컴퓨터 구매 방법 알려줘"
A: "해당 품목은 중소기업자간 경쟁제품 후보입니다. 
    세부품명을 확정하고 직접생산확인 보유 여부를 확인해야 합니다..."
→ 사용자는 계약 절차를 물었는데 직생 확인부터 요구받음
```

## 2. Silent 등급 정의

T3가 발동되면 `item_eligibility_required = true`이지만, **trigger_grade = "silent"**로 설정됩니다.

### 2.1 내부 동작 (수행함)
- Item Eligibility 레이어가 **내부적으로 실행**됩니다.
- `eligibility_context`가 생성되어 Answer Builder에 전달됩니다.
- 후보 업체 분류 시 eligibility_context를 **내부 정렬 기준**으로 사용합니다.

### 2.2 답변 노출 (제한함)
- 답변 본문에 **별도 직생/중기경쟁 섹션을 생성하지 않습니다**.
- 답변 말미에 **보조 문구 1줄만 허용**합니다:

```
ℹ️ 해당 품목이 중소기업자간 경쟁제품으로 특정되면 직접생산확인 검토가 필요할 수 있습니다.
```

### 2.3 후보표 노출 (비표시)
- 후보표에 직생 상태 열을 **전면 표시하지 않습니다**.
- 직생 데이터가 있더라도 후보표에는 기본 열(업체명, 소재지, 업종, 실적 등)만 표시합니다.
- 사용자가 후속 질문으로 직생을 요청하면 그때 Explicit으로 전환됩니다.

## 3. Explicit 전환 조건

Silent 상태에서 아래 조건 중 하나라도 충족되면 **Explicit으로 승격**됩니다:

| # | 전환 조건 | 전환 후 동작 |
|:-:|-----------|-------------|
| E1 | 사용자가 후속 질문에서 직생/중기경쟁 키워드를 사용 | T1 발동 → 직생 섹션 전면 표시 |
| E2 | 사용자가 세부품명번호를 제공 | T2 발동 → 중기경쟁 확인 전면 표시 |
| E3 | 계약경로 판정 결과 중기경쟁 검증 필수 | T5 발동 → 중기경쟁 검증 전면 표시 |

## 4. Silent 등급 답변 예시

### 예시 1: "컴퓨터 구매 방법 알려줘"

```
📌 결론
컴퓨터 구매는 추정가격에 따라 수의계약, 제한경쟁, 일반경쟁 등으로 진행합니다.

📜 법적 근거
• 시행령 제25조 제1항 제5호: 물품 수의계약 한도
• 시행령 제13조 제1항 제6호: 지역제한 경쟁

💼 실무 적용
• 2천만원 이하: 수의계약 가능
• 행안부령 기준 미만: 지역제한 경쟁입찰 가능
• 기준 초과: 일반경쟁입찰

⚠️ 주의사항
• 분할발주 금지 (감사 적발 사례)

ℹ️ 해당 품목이 중소기업자간 경쟁제품으로 특정되면 직접생산확인 검토가 필요할 수 있습니다.

⚖️ 본 답변은 참고용이며 법적 효력이 없습니다.
```

### 예시 2: "CCTV 업체 추천"

```
🏢 부산 소재 CCTV 관련 업체 후보 (○건)

1. [업체A] — 보안장비
   소재지: 부산 해운대구 | 실적: ○건/○억

2. [업체B] — 영상장비
   소재지: 부산 사상구 | 실적: ○건/○억

📊 상세 정보는 웹앱에서 확인하세요.

ℹ️ 해당 품목이 중소기업자간 경쟁제품으로 특정되면 직접생산확인 검토가 필요할 수 있습니다.
```

→ 후보표에 직생 열 없음. 보조 문구 1줄만 표시.

## 5. 금지 행위

| # | 금지 행위 |
|:-:|----------|
| S1 | T3 Silent 상태에서 답변 본문에 직생/중기경쟁 별도 섹션 생성 |
| S2 | T3 Silent 상태에서 후보표에 직생 상태 열 전면 표시 |
| S3 | T3 Silent 상태에서 "세부품명을 먼저 확정해야 합니다"로 답변 중단 |
| S4 | T3 Silent 상태에서 직생 미확인을 이유로 업체 후보 검색 차단 |
| S5 | T3가 발동되었다는 이유만으로 모든 품목 질문에 직생 보조 문구 강제 |

## 6. 보조 문구 표시 조건

보조 문구(`ℹ️ 해당 품목이 중소기업자간 경쟁제품으로...`)는 다음 **모두**를 충족할 때만 표시합니다:

1. T3가 실제로 발동됨 (item_alias_map에서 중기경쟁 후보가 1건 이상 감지됨)
2. 사용자 질문이 물품 관련 질문임 (공사·용역 질문이 아님)
3. 답변에 품목명이 언급됨

위 조건을 충족하지 않으면 보조 문구도 표시하지 않습니다.
