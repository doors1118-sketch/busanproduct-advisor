# Item Eligibility Test Cases v0.1.2 (7건 회귀 테스트)

## Test 1. 일반 품목명 다중 후보
- **질문**: "CCTV를 조달청에서 수의계약으로 사고 싶습니다. 직생이 필요한가요?"
- **기대**: 복수 후보(영상감시장치, 차량번호인식카메라) 반환 → 판단 보류 → 후보 제시 → 지역업체 검색 병행 가능 안내
- **실패**: 임의 CCTV를 찍어 중기경쟁제품이라고 단정

## Test 2. 세부품명 확정 후 경쟁제품 확인
- **질문**: "세부품명번호 4617162201 영상감시장치 수의계약 시 유의사항 알려주세요."
- **기대**: 중기경쟁제품 확인 → 직생 필수 안내 → 금액·buyer_type 추가 조건 확인 필요
- **실패**: 금액 조건만으로 수의계약 가능하다고 안내

## Test 3. 인증 만료 업체
- **질문**: "세부품명 4617162201에 대해 comp_def 업체와 계약하려고 합니다."
- **Mock**: cert_status=expired
- **기대**: 만료 감지 → "갱신 확인 필요" 분류 → 계약 가능 단정 금지
- **실패**: 과거 인증 이력만 보고 직생 보유라고 단정

## Test 4. 직접생산확인 보유 오버라이드 방지
- **질문**: "업체 B가 해당 펌프 직접생산확인을 가지고 있습니다. 수의계약 체결하면 되나요?"
- **기대**: 직생은 사전 적격성 정보로만 처리 → amount, buyer_type 등 확인 요청
- **실패**: 직생 보유만으로 수의계약 가능하다고 답변

## Test 5. 직접생산확인 미확인 업체 처리
- **질문**: "부산업체 후보 중 직접생산확인이 안 보이는 업체는 제외해야 하나요?"
- **기대**: 자동 제외하지 않음 → "증빙 확인 후보"로 표시 → 계약 전 확인 필요 안내
- **실패**: 미확인 업체를 일괄 배제

## Test 6. 직접생산확인 유효 업체 처리
- **질문**: "직생 유효한 부산업체가 있으면 바로 수의계약 가능한가요?"
- **기대**: "우선 검토 후보"로 표시 → 최종은 금액, 기관유형, 계약방식 확인 필요
- **실패**: 직생 유효만으로 계약 가능 단정

## Test 7. 세부품명 미확정 상태의 지역업체 후보 검색
- **질문**: "CCTV 부산업체 찾아줘. 직생도 봐줘."
- **기대**: 지역업체 후보 검색 가능 → 세부품명 후보 제시 → 직생 여부 단정 금지 → 후보표에 "세부품명 확인 필요"
- **실패**: 세부품명 미확정이라는 이유로 지역업체 검색까지 중단
