# Item Eligibility Trigger Test Cases

본 문서는 `item_eligibility_trigger_policy_v0_1_3.md`와 `rule_engine_priority_order_v0_1.md`의 정합성을 검증하는 테스트 케이스입니다.

---

## TC-T1. 일반 금액·계약방식 질문 (트리거 미발동)

- **질문**: "8천만원 물품 수의계약 가능한가?"
- **트리거 판정**: `item_eligibility_required = false`
  - 직생/중기경쟁 키워드 없음 ✗
  - 세부품명번호 미제공 ✗
  - item_alias_map 미해소 ✗
  - 업체 인증 데이터 미언급 ✗
  - 계약경로상 중기경쟁 불필요 ✗
- **기대 동작**:
  - ❶ buyer_type 확인 (미지정 시 추가 질문)
  - ❸ amount: 8천만원 → 수의계약 한도 초과 여부 판별
  - ❺ contract_method: 수의계약 가능 요건 검토
  - Item Eligibility 레이어 **완전 스킵**
- **기대 답변 핵심**: 금액 기준 수의계약 한도(2천만원/5천만원/1억원 등) 초과 여부, 소기업·소상공인 특례 가능 여부
- **실패 조건**: 직접생산확인 확인부터 요구

## TC-T2. 지역업체 활용 범용 질문 (트리거 미발동)

- **질문**: "부산업체 쓸 수 있는 방법 알려줘"
- **트리거 판정**: `item_eligibility_required = false`
  - 직생/중기경쟁 키워드 없음 ✗
  - 세부품명번호 미제공 ✗
  - 품목명 자체 미언급 ✗
- **기대 동작**:
  - ❻ local_preference: 지역제한 경쟁(시행령 제13조), 공동수급체 참여비율(제88조), 지역상품 조례
  - ❼ policy_company: 사회적기업, 여성기업 등 정책기업 특례
  - ❹ procurement_route: MAS 2단계 지역제한, 쇼핑몰 활용
  - Item Eligibility 레이어 **완전 스킵**
- **기대 답변 핵심**: 지역제한 가능 기준, 조달경로별 지역업체 활용법, 정책기업 특례
- **실패 조건**: 중기경쟁제품/직접생산확인으로 답변 중단

## TC-T3. 지역업체 검색 + 직생 병행 요청 (트리거 발동)

- **질문**: "CCTV 부산업체 찾아줘. 직생도 봐줘."
- **트리거 판정**: `item_eligibility_required = true`
  - T1: 키워드 "직생" 포함 ✓
- **기대 동작**:
  - ❻ local_preference: 지역업체 후보 검색 **즉시 실행** (세부품명 미확정과 무관)
  - ❽ item_eligibility:
    - item_alias_map으로 CCTV → 세부품명 후보(영상감시장치, 차량번호인식카메라 등) 제시
    - 세부품명 미확정이므로 중기경쟁 여부 **단정 금지**
    - 후보표에 "세부품명 확인 필요" 상태 표시
- **기대 답변 핵심**:
  - 지역업체 후보 목록 (검색 결과)
  - 세부품명 후보 목록 (사용자 선택 유도)
  - "세부품명 확정 후 중기경쟁제품 여부와 직생 필요 여부를 이어서 확인할 수 있습니다."
- **실패 조건**: 세부품명 미확정으로 지역업체 검색 중단

## TC-T4. 세부품명 명시 (트리거 발동)

- **질문**: "세부품명번호 4617162201 영상감시장치"
- **트리거 판정**: `item_eligibility_required = true`
  - T2: 세부품명번호 명시 ✓
- **기대 동작**:
  - ❽ item_eligibility:
    - `sme_competition_product_item` 조회 → 중기경쟁제품 확인
    - 경쟁제품이면 직접생산확인 필수 여부 안내
    - `buyer_type`, `amount` 등과 결합하여 종합 안내
- **기대 답변 핵심**: 해당 세부품명의 중기경쟁제품 여부, 직생 필수 여부, 추가 확인 필요 사항
- **실패 조건**: 일반 계약경로만 보고 중기경쟁제품 검토 누락

## TC-T7. 직생 유효 업체 (트리거 발동, 단정 금지 검증)

- **질문**: "직생 유효한 부산업체가 있으면 바로 수의계약 가능한가요?"
- **트리거 판정**: `item_eligibility_required = true`
  - T1: 키워드 "직생" 포함 ✓
- **기대 동작**:
  - ❽ item_eligibility: 직생 유효 확인
  - 그러나 **계약 가능 단정 금지** → "우선 검토 후보"로만 분류
  - ❸ amount, ❶ buyer_type, ❺ contract_method 결합 필요 안내
- **기대 답변 핵심**: "직생 유효는 사전 적격성 정보이며, 최종 계약 가능성은 금액·기관유형·계약방식을 함께 검토해야 합니다."
- **실패 조건**: 직생 유효만으로 수의계약 가능 단정

## TC-T8. 직생 미확인 업체 (트리거 발동, 자동 배제 금지 검증)

- **질문**: "부산업체 후보 중 직접생산확인이 안 보이는 업체는 제외해야 하나요?"
- **트리거 판정**: `item_eligibility_required = true`
  - T1: 키워드 "직접생산확인" 포함 ✓
- **기대 동작**:
  - ❽ item_eligibility: 직생 미확인 상태 확인
  - **자동 배제 금지** → "증빙 확인 후보"로 분류
  - 공공구매종합정보망 또는 업체 제출 증빙으로 확인 안내
- **기대 답변 핵심**: "직생 미확인은 자동 배제 사유가 아닙니다. 증빙 확인 후보로 분류하며, 추가 확인을 권장합니다."
- **실패 조건**: 미확인 업체 일괄 배제

## TC-T9. 중기경쟁제품 아닌 품목 (트리거 발동 후 결과 처리)

- **질문**: "소화기 직생 필요한가요?"
- **트리거 판정**: `item_eligibility_required = true`
  - T1: 키워드 "직생" 포함 ✓
- **기대 동작**:
  - ❽ item_eligibility:
    - item_alias_map으로 소화기 → 세부품명 해소
    - `is_sme_competition_product = false`인 경우
    - **직생을 필수 검토요건처럼 제시하지 않음**
- **기대 답변 핵심**: "현재 세부품명 기준 중소기업자간 경쟁제품으로 확인되지 않습니다. 직접생산확인은 필수 검토요건이 아닐 수 있습니다."
- **실패 조건**: 비경쟁제품에 직생을 필수요건처럼 안내
